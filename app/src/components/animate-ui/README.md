# animate-ui

Components in this directory are adapted from [Animate UI](https://animate-ui.com)
by Elliot Sutton, used under its MIT + Commons Clause licence — which permits use
and modification inside an application or website, and forbids only reselling the
components themselves in their original form.

They are copied rather than installed (the shadcn-registry model), so they are
retuned here to this site's semantic colour tokens instead of the hardcoded
palettes the originals ship with, and to respect `prefers-reduced-motion`.
